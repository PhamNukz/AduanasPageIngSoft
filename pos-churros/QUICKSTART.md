# ⚡ Inicio Rápido - POS Churros

## 🚀 3 Pasos para Empezar

### 1️⃣ Iniciar Servidor

Elige tu método favorito:

**Visual Studio Code:**
```
1. Instala extensión "Live Server"
2. Clic derecho en index.html → "Open with Live Server"
```

**Python:**
```bash
python -m http.server 8000
# Abre: http://localhost:8000
```

**Node.js:**
```bash
npx http-server -p 8000
# Abre: http://localhost:8000
```

### 2️⃣ Iniciar Sesión

```
Usuario: admin
Contraseña: 1234
```

### 3️⃣ Crear tu Primer Pedido

1. Ingresa nombre del cliente
2. Selecciona "Churros Rellenos x3"
3. Cantidad: 2
4. Clic en "Agregar al Pedido"
5. Clic en "Finalizar e Imprimir"
